## Hi, I'm Junka 👋

I enjoy working close to the metal: designing high-performance networking and Linux tooling, exploring GPU compute and inference, and learning by building media and image-processing systems from first principles.

> ⚡ My favorite problems sit at the boundary between software, hardware, and the network.

## 🚀 Featured projects

| Project | What it does |
| --- | --- |
| [**HAMi-core**](https://github.com/junka/HAMi-core) | Transparent, in-container GPU resource control for CUDA workloads. |
| [**vkop**](https://github.com/junka/vkop) | A simple AI inference engine based on Vulkan. |
| [**vkcompbench**](https://github.com/junka/vkcompbench) | GPU compute capability benchmarking with Vulkan. |
| [**ffmime**](https://github.com/junka/ffmime) | Finds MIME codecs for MSE in WebAssembly. |
| [**tsanalyze**](https://github.com/junka/tsanalyze) | MPEG-TS parser built for learning and experimentation. |
| [**ffpic**](https://github.com/junka/ffpic) | Hands-on image decoding for BMP, PNG, JPEG, WebP, and HEIF. |
| [**pktperf**](https://github.com/junka/pktperf) | Linux `pktgen` extensions and helper scripts for packet testing. |
| [**pycbpf**](https://github.com/junka/pycbpf) | Compiles classic BPF into C code for BCC workflows. |
| [**j2depkt**](https://github.com/junka/j2depkt) | A DSL inspired by Scapy for packet capture and DPDK `RTE_FLOW`. |
| [**feishu-bot-webhook-action**](https://github.com/junka/feishu-bot-webhook-action) | GitHub Action that forwards repository events to a Feishu bot. |
| [**private2fa**](https://github.com/junka/private2fa) | Open-source TOTP authenticator vault. |
| [**arxiv_feishu_bot_action**](https://github.com/junka/arxiv_feishu_bot_action) | Collects arXiv papers and sends personalized Feishu updates. |
